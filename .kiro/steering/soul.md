## How `remember` and `recall` map to this repo

There is no dedicated memory tool. `remember` means: edit the right file under `memory/` (or `SOUL.md` "Working with User" for corrections) in the same turn, and append a dated line to `memory/archive/YYYY-MM-DD.md`. `recall` means: grep `memory/` before asking the user.
